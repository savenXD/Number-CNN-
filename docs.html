2. CNN Layer Architecture

Input Layer 28 × 28 Grayscale Image
Conv2D Layer 1 32 filters, 3×3 kernel, ReLU
MaxPooling2D Layer 1 2×2 pool size
Conv2D Layer 2 64 filters, 3×3 kernel, ReLU
MaxPooling2D Layer 2 2×2 pool size
Flatten Reshape 2D feature maps to 1D vector
Dense Layer 128 units, ReLU activation
Dropout Layer Rate: 0.3 (Regularization)
Output Dense Layer 10 units, Softmax activation (Digits 0–9)

3. Preprocessing Pipeline

  1. Base64 Decoding: Canvas PNG drawing received via API payload.
  2. Grayscale & Color Inversion: White canvas (255) converted to white digit on black background (MNIST convention).
  3. Bounding Box Crop: Extracts non-zero stroke pixels without cropping out digit edges.
  4. Aspect Ratio Preserved Resizing: Resizes stroke inside a 20×20 bounding box preserving proportions.
  5. Centered 28×28 Frame: Pads outer margins to produce centered 28×28 matrix.
  6. Normalization & Reshaping: Scales pixels to [0.0, 1.0] and reshapes to batch shape (1, 28, 28, 1).

4. FastAPI Endpoint Reference

POST /predict

Accepts JSON {"image": "data:image/png;base64,..."} and returns predicted digit + raw Softmax float output for digits 0–9.

Returns server operational status and model file readiness.
